# Changelog

## [Unreleased]

## [0.2.0] - 2026-08-02

- Stacked the SQL query builder above the query editor and results grid for improved readability.
- Added a schema-aware column picker with removable projection chips and helpers for row and non-null value counts.
- Improved query-builder accessibility and added a clear error when no valid table or view is selected.

## [0.1.0] - 2026-08-02

- Initial SQLite View workbench.
- Added database library, schema tree, paged record grid, CRUD, SQL execution, query builder, CSV and SQL transfer, charts, command logging, compaction, and optional SQLCipher conversion.
